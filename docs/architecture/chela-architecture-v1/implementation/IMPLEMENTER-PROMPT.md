# 交给 Sol / Astra 的开工指令

你负责在**现有 Chela 仓库**中实现这个架构包。请先阅读 README、docs/architecture/00-decisions.md、01-system.md、contracts/ 和 implementation/PLAN.md，再执行 S00，然后按门禁持续实施。需要讨论真实冲突时带着具体代码或运行证据提出问题；普通技术取舍自行处理。

## 用户已经明确的产品意图

Chela 是同一个持续存在的个人助手，拥有多个会话和并行任务。人格、适用的长期记忆与短期心情可以连续；会话的工作上下文、工具、取消和审批必须隔离。不要再把每个会话实现成一个没有共同经历的新角色。

Go 管宿主、业务状态、调度、权限、记忆、主动性与恢复；MyGo + React/WebView承载现有设计；应用打包私有Node，Pi AgentSession 是内部唯一Agent循环。Codex/OpenCode 是独立外部执行器，用户应能回到原终端现场。模型目录和路由从Magpie适配，Chela按角色绑定模型，不重复维护一份全球目录。

完整能力包含跨会话记忆、上下文压缩、空闲整理、关注事项、自然语言计划、晨报、主动提醒、持续情绪、独立桌宠和扩展生态。任务、日历和看板共享记录；查看回复与完成任务分开，不建立强制交付物/验收流程。保留旧版备忘录、PTY、记忆、审批恢复等有价值能力。

## 开始时具体做什么

1. 只读检查当前分支、未提交文件、实际Go/worker/UI入口、旧Electron归档、数据目录与AGENTS说明。不要 reset、覆盖未提交代码或直接套用远端旧main。
2. 对照08-evidence和迁移矩阵，列出当前已实现/部分实现/未实现/待核验的能力。远端旧基线只作参考。
3. 找出首个未满足的阶段，建立实际文件到模块的映射，复用已有正确实现。完成必要备份和可回退检查点后动手。
4. 优先证明PiBridge闭环：Go持久源、原始Pi entries、真正await的checkpoint、唯一工具执行路径、取消与恢复、compaction门禁。不要先搭大量空模块或重复美化UI。
5. 每阶段跑有价值的契约/集成/故障场景，给出真实结果，然后继续下一阶段。不要仅回复一份计划就停下。

## 不得自行改变的约束

- 一个assistant_id，多个独立session/branch；每个branch一个canonical writer。
- AgentSession唯一内部loop，Go SQLite唯一durable source；worker只是可重建投影。
- 默认后续输入由Go持久队列拥有；不要同时放进Pi followUp再创建新Run。明确steer仍属于当前Run。
- 原始Pi entry/工具调用/提供商字段完整保存；不能只保存简化聊天气泡。
- 不能把AgentSession.subscribe的async监听当提交屏障；PiBridge必须实测确保host ack前不继续受控执行。
- compaction只有Pi执行；Go负责SafeCut、覆盖和原子提交。提交失败或ack不明时不能继续使用tentative状态。
- managed工具的最终execute必须走Go网关；trusted-native和外部执行器不能被虚假宣称全受网关控制。
- 重启恢复建新Run并回查真实状态；工具调用配对不完整时走安全恢复分支。未知副作用不得盲重放。
- 记忆范围在检索前过滤，来源/版本/有效期可查；遗忘要防后台重新学回。
- mood属于Chela自身的共享角色状态，不能替换成用户情绪分析或记忆相关性分数。
- 模型输出只是提议；任务完成、工具成功、审批与数据写入由正式业务状态决定。
- 关闭主窗口不停止已提交Run；显式退出按规则结束owned进程，未启动时不假装后台仍在工作。

## 依赖和迁移

用户偏好可以使用 `^` 依赖范围，但正式构建必须提交lockfile并经过版本兼容测试；不要启动时在线漂移依赖。当前文档记录的版本是证据时间点，不是永久不许升级的限制。MyGo生成bindings不能触发真实业务初始化。

实际Magpie接口、CLI能力、操作系统窗口/PTY行为以S00和集成验证为准，不编造支持情况。先适配现有端口，再替换底层。旧数据导入可重跑、有legacy ID映射和对账；未知来源不得凭空补全，未完成切换验收前保留原数据。

## 每阶段反馈格式

用简洁中文说明：这次用户现在能做什么；关键代码变化；运行过哪些必要验证及结果；下一阶段解决什么。遇到真正阻塞，明确文件/调用/错误和已经尝试的安全替代。没有实际执行的测试不要写通过，不把第三方示例的性能写成Chela实测。

最终交付应包括可运行实现、迁移/回退方式、A01–A46的实际验收结果与确切剩余限制。请从S00开始，持续完成已授权且可执行的工作。
